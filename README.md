# VanishEffects

Плагин для Spigot/Paper (Minecraft 1.20.x), который добавляет команду `/v` с тремя
разными визуальными эффектами исчезновения — все через одну и ту же команду,
просто с разным первым аргументом.

## Команды

| Команда                     | Что делает                                                        |
|------------------------------|--------------------------------------------------------------------|
| `/v fire [игрок]`            | Огонь + звук горения, затем игрок пропадает (ваниш)                |
| `/v bats [игрок]`            | Стая летучих мышей кружит вокруг, затем игрок пропадает             |
| `/v lightning [игрок]`       | Серия визуальных молний (без урона), затем игрок пропадает          |
| `/v show [игрок]`            | Возвращает видимость с мягким эффектом появления                    |

Если аргумент `[игрок]` не указан — эффект применяется к самому себе.
Чтобы применить эффект к **другому** игроку, нужно право `vanisheffects.others`
(по умолчанию — у оператора).

## Права (permissions)

- `vanisheffects.use` — использовать `/v` на себе (по умолчанию есть у всех)
- `vanisheffects.others` — применять `/v` к другим игрокам (по умолчанию — op)
- `vanisheffects.see` — видеть игроков, которые находятся в ваниш-режиме (по умолчанию — op)

## Сборка

Нужен установленный Maven и JDK 17+.

```bash
mvn clean package
```

Готовый файл появится в `target/VanishEffects.jar`.

> **Важно:** `spigot-api` в Maven Central не публикуется как готовый jar — обычно
> его нужно собрать локально через [BuildTools](https://www.spigotmc.org/wiki/buildtools/)
> либо (проще) заменить зависимость в `pom.xml` на **Paper API**, который
> лежит в открытом репозитории `https://repo.papermc.io/repository/maven-public/`
> и не требует локальной сборки. Комментарий с этой альтернативой уже есть в `pom.xml`.

## Установка

1. Соберите или скачайте `VanishEffects.jar`.
2. Положите его в папку `plugins/` вашего сервера (Spigot/Paper 1.20.x).
3. Перезапустите сервер.
4. Выдайте себе право `vanisheffects.use` (обычно уже есть по умолчанию) и, если
   нужно применять эффекты к другим — `vanisheffects.others`.

## Структура проекта

```
VanishEffects/
├── pom.xml
├── README.md
└── src/main/
    ├── java/ru/example/vanisheffects/
    │   ├── VanishEffectsPlugin.java   — главный класс плагина
    │   ├── VanishManager.java         — скрытие/показ игроков
    │   ├── VanishCommand.java         — обработка /v и tab-completion
    │   ├── JoinListener.java          — скрывает ваниш-игроков от новых
    │   └── effects/
    │       └── VanishEffects.java     — сами 3 визуальных эффекта
    └── resources/
        └── plugin.yml
```

## Настройка эффектов

Все параметры (длительность, количество частиц, звуки, радиус) находятся
в `VanishEffects.java` — каждый эффект оформлен как отдельный метод, их легко
подправить под себя (например, поменять длительность анимации или частицы).
